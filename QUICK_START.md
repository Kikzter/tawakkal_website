## 🚀 Deployment Option 1: GitHub Pages (Recommended - Free)

### Steps:

1. **Create GitHub Account** (if you don't have one)
   - Go to [github.com](https://github.com)
   - Click "Sign up"
   - Create a free account

2. **Open Command Prompt/PowerShell**
   - Press `Win + R`
   - Type `cmd` or `powershell`
   - Navigate to your project:
     ```
     cd c:\Users\mdnay\Documents\tawakkal_website
     ```

3. **Initialize Git**
   ```
   git init
   git config user.name "Your Name"
   git config user.email "your-email@example.com"
   git add .
   git commit -m "Initial Tawakkal website"
   ```

4. **Create Repository on GitHub**
   - Go to [github.com/new](https://github.com/new)
   - Repository name: `tawakkal-website`
   - Click "Create repository"
   - Follow the instructions to push your code

5. **Enable GitHub Pages**
   - Go to your repository
   - Click "Settings"
   - Scroll to "Pages"
   - Select "main" branch, "/" folder
   - Your site will be live at: `https://yourusername.github.io/tawakkal-website`

## 🚀 Deployment Option 2: Netlify (Easiest - No Command Line!)

### Steps:

1. Go to [netlify.com](https://netlify.com)
2. Click "Deploy" button or "Deploy manually"
3. Drag and drop your `tawakkal_website` folder
4. **Done!** Your site is live with a URL like: `https://cool-name.netlify.app`

## ❓ Common Issues

**Images not showing?**
- Check file names match exactly
- Make sure images are in `assets/` folder

**Website looks different locally?**
- Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser

**Contact form not working?**
- It opens your email client - that's normal!
- You'll send the email from your own email
