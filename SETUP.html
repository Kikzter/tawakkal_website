💻 Option 2: Deploy with GitHub Pages

  1. Create a free account at github.com
  2. Create a new repository named tawakkal-website
  3. Open Command Prompt and run:
    cd c:\Users\mdnay\Documents\tawakkal_website git init git config user.name "Your Name" git config user.email "your-email@example.com" git add . git commit -m "Add Tawakkal website" git remote add origin https://github.com/YOUR-USERNAME/tawakkal-website.git git branch -M main git push -u origin main
  4. Go to repository Settings → Pages → Enable GitHub Pages
  5. Your site will be at: https://YOUR-USERNAME.github.io/tawakkal-website
⚠️ Note: Make sure Git is installed on your computer. Download from git-scm.com if needed.
